# SPX 游戏引擎文档

欢迎使用SPX游戏引擎！SPX是一个兼容Scratch的2D游戏引擎，基于Go+和XGo构建，让游戏开发变得简单而有趣。

## 🎮 示例游戏

SPX包含18个示例游戏，涵盖不同的游戏类型和技术：

- **01_AircraftWar** - 飞机大战
- **02_BetaGo** - 五子棋
- **03_Dinosaur** - 恐龙跳跃  
- **04_FlappyCalf** - 飞翔的小牛
- **05_MazePlay** - 迷宫游戏
- **08_NinjaFight** - 忍者格斗
- **18_Physic** - 物理演示
- 更多游戏请查看 [spx_demos目录](../../spx_demos/)
