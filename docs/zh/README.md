## 🎮 示例游戏

SPX包含多个教程demo，从基础到进阶循序渐进，帮助你掌握游戏开发技能：

- **00-Blank** - 最小空项目，提供干净的项目模板，适合从零开始创建游戏
- **00-Hello** - 入门教程，学习基本的文本输出和事件处理机制
- **01-Weather** - 对话系统，掌握角色对话、消息广播和服装切换功能
- **02-Dragon** - 碰撞检测，学习精灵移动、碰撞检测和得分系统
- **03-Clone** - 精灵克隆，理解对象克隆、点击事件和精灵销毁机制
- **04-Bullet** - 子弹射击，掌握连续克隆、跟随鼠标位置和边界检测
- **05-Animation** - 动画与交互，学习敌人AI、生命值系统和精灵间交互
