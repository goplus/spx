# 快速开始

本目录包含spx游戏引擎的入门指南，帮助新开发者快速上手。

## 环境安装指南
### mac
```
# 0. clone repo
git clone https://github.com/goplus/spx
cd spx 

# 1. 安装 go # v1.23.0 

## 确保 go/bin 加入到 PATH中

# 2. 安装 xgo # 1.5.1
git clone https://github.com/goplus/xgo.git
cd xgo
./all.bash

# 3. 确保已经安装了 make
# 4. 初始化 spx 环境
make init

```
