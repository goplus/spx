# 快速开始

本目录包含spx游戏引擎的入门指南，帮助新开发者快速上手。

## 环境安装指南

我们提供了一键安装脚本，大大简化了环境搭建过程：

### 🚀 一键安装 (推荐)

#### macOS/Linux
```bash
# 1. 克隆仓库
git clone https://github.com/goplus/spx
cd spx

# 2. 运行一键安装脚本
chmod +x init.bash
./init.bash
```

#### Windows
```bat
# 1. 克隆仓库 (在 Git Bash 或 PowerShell 中)
git clone https://github.com/goplus/spx
cd spx

# 2. 运行一键安装脚本
init.bat
```

**⚠️ Windows 重要提示:**
- 脚本会自动检测并使用 MSYS2 环境
- 如果未安装 MSYS2，请先访问 https://www.msys2.org/ 安装
- 安装完成后，请始终在 **MSYS2 UCRT64** 终端中运行 SPX 相关命令

### 📋 手动安装 (备选方案)

如果一键安装遇到问题，可以按照以下步骤手动安装：

<details>
<summary>点击展开 macOS 手动安装步骤</summary>

```bash
# 0. clone repo
git clone https://github.com/goplus/spx
cd spx 

# 1. 安装 Go v1.23.0
# 方式一：使用 Homebrew (推荐)
brew install go@1.23

# 验证安装
go version  # 应该显示 go version go1.23.x

# 确保 Go 二进制文件路径已加入 PATH
echo 'export PATH=$PATH:/usr/local/go/bin:$HOME/go/bin' >> ~/.zshrc
source ~/.zshrc

# 2. 确保已经安装了 make
make --version || xcode-select --install

# 3. 安装 xgo
git clone https://github.com/goplus/xgo.git
cd xgo
./all.bash
cd ..

# 4. 初始化 spx 环境
make setup
```
</details>

<details>
<summary>点击展开 Windows 手动安装步骤</summary>

```bash
# 在 MSYS2 UCRT64 终端中执行：

# 0. clone repo
git clone https://github.com/goplus/spx
cd spx

# 1. 更新 MSYS2
pacman -Syu

# 2. 安装开发工具链
pacman -S --needed base-devel mingw-w64-ucrt-x86_64-toolchain
pacman -S make zip unzip bash git

# 3. 安装 Go
pacman -S mingw-w64-ucrt-x86_64-go

# 4. 安装 xgo
git clone https://github.com/goplus/xgo.git
cd xgo
./all.bash
cd ..

# 5. 初始化 spx 环境
make setup
```
</details>
